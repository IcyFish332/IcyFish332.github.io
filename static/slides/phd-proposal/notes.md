## 可能的提问 → 备用页

- **长程价值函数训不好怎么办？** → 备用 1（风险对策）：统计式基线兜底、与组内基线自适应切换；多版本经验预训练缓解冷启动 [34]。
- **和 GRPO / PPO / 自蒸馏等方法相比的定位？** → 备用 2（方法族对比表）。
- **和 AlphaEvolve、DGM 的区别？** → 备用 3：它们改进任务解或代码，权重冻结；本课题让权重进入回路。
- **自我改进场景具体是什么？** → 研究内容三：环境状态为代码库（DGM 类）或解的档案（AlphaEvolve 类）；先在评估快的短任务上验证，再扩展长度。
- **奖励投机如何防范？** → 可验证奖励作为最终依据、评估器置于回路外；可补充轮转中 SWE rollout 的反 hack 规则实践。
- **基础理论**：GAE 中 λ 的偏差—方差权衡；重要性采样权重随序列长度的方差爆炸，以及 token 级截断 / 裁剪的作用；PPO clip 与离策略修正的关系。
- **具体数字** → 备用 4（ET / CrEST 结果表）、备用 5（AWorld 耗时表与 rollout 曲线）。
